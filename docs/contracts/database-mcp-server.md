# 数据库 MCP Server 接入约定

> 状态：草案 v0（2026-10-02），供外部 Server 责任方与小维双方确认；**外部 Server 责任方：待定**。本文只约定外部 Server 必须满足什么、小维接入时怎样验收；方向与分工见 [ARCHITECTURE.md](../../ARCHITECTURE.md) §5“数据库能力 MCP 化”，实施阶段见 [DEVELOPMENT_PLAN.md](../../DEVELOPMENT_PLAN.md) §6。当前小维尚未接入任何真实外部 Server，下述能力均为约定，不是已验证事实。

**OpenAI Agents SDK 负责 Agent Loop；小维负责权限、受治理工具执行、证据真实性和数据边界。** 外部 Server 只负责连接与执行，不承担授权、SQL 校验、证据与展示判断，也不能以自身检查替代小维治理；小维的检查同样不能替代 Server 的执行约束。

## 1. 账号与能力

**a. 只读账号。** 只读 Server 连接数据库时只使用只读账号；该账号在数据库侧没有任何写、DDL、授权或配置修改权限。账号凭据只在 Server 内保存，不经 MCP 返回，也不出现在日志与错误中。

**g. 读写分开。** 只读 Server 不提供任何写工具，也不存在能执行写语句的参数组合。写能力（以后的 DDL）由单独部署的写 Server 提供，使用受限写账号，只提供结构化动作（如 `add_partition`、`add_column`），由 Server 按模板生成语句，不接受任意 SQL 或 DDL 文本。写 Server 执行前核对小维给出的批准凭证（与具体动作、目标和关键参数绑定，过期或不匹配即拒绝）；凭证格式与校验方式在首个写场景计划中约定。首版不接入写 Server。

## 2. 执行

**b. 原样执行一条语句。** 只执行小维发来的那一条 SQL：不改写、不追加（包括不加 `LIMIT`、不补库名、不拼接其他语句），收到多条语句时拒绝。只读 Server 只接受 `SELECT` 或 `WITH` 开头的查询语句与以 `EXPLAIN LOGICAL ` 开头的语句，其余一律拒绝且不发往数据库；开头合规的语句中含 `INTO OUTFILE`、`FILES()` 等导出或外部访问时同样拒绝；这是 Server 侧的纵深防御，不替代小维的 SQLGuard。结果中返回实际执行的完整语句，小维只用它核对与发出的语句一致；它不证明数据库实际的执行行为，只读与零执行的保证来自只读账号与第 k 条验收。

**c. 会话限额。** 每次执行前在同一会话设置 `query_timeout`、`query_mem_limit`、`time_zone`（取值由小维按目标配置在每次调用中给出，Server 不得放宽），并回读确认；设置或回读不符时不执行语句，返回固定错误码。

**d. EXPLAIN 级别。** 执行计划只用固定的显式级别 `EXPLAIN LOGICAL`（P2 Task 0 在 StarRocks 4.1.4 上实测选定）。禁止裸 `EXPLAIN`：其级别取自 FE 可变配置 `query_explain_level`，可被设为 ANALYZE 而实际执行查询。`EXPLAIN COSTS` 会输出列的真实 min/max，`EXPLAIN VERBOSE` 会输出资源组名，均不得使用。EXPLAIN 级别由小维决定并在语句中写明，Server 不替换级别，其他 EXPLAIN 形式按第 b 条拒绝；目标数据库版本不是 4.1.4 时，须在该版本上复核零执行与输出内容后才能接入。

**e. 有界结果与固定错误。** 返回的行数、总字节与单值大小都有上限（取值由小维按目标配置在每次调用中给出，Server 不得放宽），超限时停止读取、截断并明确标记，不返回越界部分。错误只返回约定的固定错误码（如权限不足、服务端超时、客户端期限、连接中断、结果契约不符、未知集群、认证失败），不携带连接信息、账号、数据库原始报错文本或被执行的 SQL。“中断”包括小维取消请求或 HTTP 连接断开：超时或中断时 Server 须终止对应的数据库查询，优先用 `KILL QUERY`；只断开连接的做法，须在第 k 条验收中用 `SHOW PROCESSLIST` 确认 StarRocks 确实因此停止该查询才算满足（客户端断开后数据库是否立即停止查询尚无实测证据）。不自动重试执行。这一要求严于当前本地直连：小维现在超时或取消时只断开连接，依靠数据库侧 `query_timeout` 兜底。小维客户端的调用超时须大于 Server 端的 `query_timeout`，使服务端超时先于客户端放弃触发并返回固定错误码。

## 3. 调用方式

**f. 认证。** 小维到 Server 的认证当前只支持静态 Bearer 令牌：令牌由部署环境以安全引用提供，经 HTTPS 发送（明文 HTTP 只用于 loopback 测试）。Server 拒绝缺失或错误的令牌，且拒绝时不执行任何数据库操作。其他认证方式需要小维先实现并验证。服务凭据只代表小维这个调用方，不代表最终用户授权；最终用户的授权由小维判定。

**h. 多集群。** 每次调用携带集群标识，Server 按标识选择对应连接；未知集群直接拒绝，不回退到默认集群。不同集群的连接、账号与限额互不共用。

**i. 工具 schema 与版本。** 每个工具的参数与结果 schema 由双方书面约定并带版本号；结果至少包含列名、行、是否截断、行数、耗时与实际执行的语句。值类型约定：DECIMAL 以定点字符串返回（不转浮点）；日期时间带时区偏移；NULL 保留为 null，不转空串；二进制与未约定的类型拒绝整个结果并返回结果契约不符；列名不得重复，重复时同样拒绝。schema 变更须提前通知，小维同步更新登记与策略后才启用；小维启动时核对远端 schema，未约定的变化按拒绝处理。

**j. 请求编号。** 小维在每次调用中传入请求编号，Server 写入自己的日志，便于双方按编号排障；日志同样不记录凭据与结果数据。

## 4. 小维接入验收

**k.** 小维接入一个 Server（或其新版本、新集群）前，在测试环境逐项验证并记录 Server 版本、数据库版本与结果：

| 验收项 | 期望 |
| --- | --- |
| 只读账号写入 | 经 Server 发出写语句与 DDL，数据库拒绝，数据不变 |
| EXPLAIN 零执行 | 管理员把 FE `query_explain_level` 设为 ANALYZE 后，`EXPLAIN LOGICAL` 仍只返回计划：执行期必失败的查询不报错，审计扫描行数为 0、无新 Profile；同一环境下裸 `EXPLAIN` 的阳性对照确实执行；结束后恢复配置 |
| 超时与限额 | `query_timeout`、`query_mem_limit` 回读一致并实际生效；回读不符时不执行 |
| 截断标记 | 行数、总字节、单值三种上限各自触发截断与标记 |
| 原样执行 | 返回的实际语句与发出的一致；多语句被拒绝 |
| 语句白名单 | 裸 `EXPLAIN`、`EXPLAIN COSTS`/`VERBOSE`/`ANALYZE`、写语句、DDL、`SET`、`SELECT ... INTO OUTFILE`、含 `FILES()` 的查询等被拒绝，没有数据库请求 |
| 值类型 | DECIMAL 为定点字符串、日期时间带时区偏移、NULL 保留；二进制或未约定类型、重复列名返回结果契约不符 |
| 取消即终止 | 小维取消请求或断开 HTTP 连接后，`SHOW PROCESSLIST` 中对应查询消失（用 `KILL QUERY` 或经实测确认有效的断开连接），不重试 |
| 错误不泄露 | 权限、超时、中断、语法等错误只返回固定错误码，不含连接信息、账号、原始报错或 SQL |
| 未知集群 | 返回拒绝，没有数据库请求 |
| 认证失败 | 缺失或错误的令牌被拒绝，没有数据库请求 |

小维侧另验证：治理拒绝（越权对象、列、函数，未授权集群，预算耗尽）时没有发往 Server 的请求。

## 5. 责任方
